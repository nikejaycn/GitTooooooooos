# GitCurrent v0.1.0-test.9

这是 GitCurrent 的第九个 GitHub 测试版本，重点验证主窗口改动文件浏览、历史操作和
分支侧边栏交互。本版本不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- Working Copy 与 History 使用统一的改动文件浏览器，文件状态、选中高亮和 Diff 展示
  保持一致。
- History 下方文件列表与 Diff 区域支持独立拖拽调整尺寸，内容会随分栏尺寸同步布局，
  分割线悬停时显示原生拖拽光标。
- Local Branches 与 Remote Branches 的选中状态使用和其他侧边栏栏目一致的高亮效果，
  并补充分支展开、检出和删除等上下文操作。
- 为提交图谱、单个提交和多选提交补充上下文菜单，支持检出、按顺序 Cherry-pick、生成
  Patch，以及打开远程提交页面。
- 为工作区和提交历史补充批量 Patch 导出、提交比较和远程仓库链接能力，操作经过统一的
  可恢复计划与 Git 队列执行。
- 继续拆分主窗口、侧边栏、Git 执行层和操作计划模块，并补充对应的 UI、解析器和真实
  Git 仓库测试。

## 兼容性

- 保留现有 Bundle ID、偏好设置 Key 和数据格式，覆盖旧测试版不会丢失最近仓库与本地
  设置。
- 构建产物为 `GitCurrent.app`，应用版本为 `0.1.0 (9)`。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 内置 Git/Git LFS 工具链为 Apple Silicon 版本，因此本测试版仅支持 arm64 Mac。
- 本次 GitHub release 仅发布源码和测试说明，不附带打包或签名安装包；低版本兼容性由
  GitHub Actions 负责验证。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`GitCurrent.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：222 项通过，3 项环境相关用例按预期跳过。
- macOS arm64 Debug 构建通过。
- `git diff --check` 通过，`sites/current-macos-prototype/` 保持在忽略列表中。
