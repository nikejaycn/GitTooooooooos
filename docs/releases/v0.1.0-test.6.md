# GitCurrent v0.1.0-test.6

这是 GitCurrent 的第六个 GitHub 测试版本，重点验证主窗口各功能域拆分后的交互与
可维护性。本版本不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- 将 History、Working Copy、File Insights、Stash 和操作日志拆为独立工作区，
  降低主窗口视图的状态耦合。
- 抽取 Commit 面板、Diff 控件和仓库侧边栏展示逻辑，统一同类组件的交互与样式。
- History 工作区独立管理图表选择、搜索范围、跳转和 Hard Reset 确认状态。
- Working Copy 工作区独立管理筛选、提交草稿、丢弃确认和可调整分栏内容。
- 最近关闭仓库历史与操作活动日志迁入应用支持层，并修正注入
  `UserDefaults` 时写入目标不一致的问题。
- 操作活动保持最新优先和 100 条上限，Git 操作标题集中由同一目录生成。
- 补充 History、Working Copy、File Insights、侧边栏、工作区历史和操作活动测试。

## 兼容性

- 保留现有 Bundle ID、偏好设置 Key 和数据格式，覆盖旧测试版不会丢失最近仓库
  与本地设置。
- 构建产物为 `GitCurrent.app`。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`GitCurrent.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：190 项通过，3 项环境相关用例按预期跳过。
- macOS arm64 Debug 与 Release 构建通过。
- Release ZIP 同时提供 SHA-256 校验文件。
