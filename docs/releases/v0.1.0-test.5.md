# GitCurrent v0.1.0-test.5

这是 GitCurrent 的第五个 GitHub 测试版本，重点验证主窗口与应用层的结构化重构。
本版本不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- 主窗口依赖按仓库、历史、工作区、Diff、分支、标签、远程等功能域分组，
  降低根视图与应用模型之间的耦合。
- 抽取远程、标签、暂存、Git LFS、合并和 Hooks 等可复用对话框组件。
- 新增独立的 `CurrentAppSupport` 模块，集中管理应用偏好和外部 Diff/Merge
  工具调用。
- 应用偏好支持注入与独立测试，最近仓库、界面设置和功能选项继续兼容现有数据。
- 工作区状态筛选逻辑从主视图抽离并补充单元测试。
- 精简主窗口和应用模型中的重复实现，为后续拆分 History、Working Copy 和
  File Insights 工作区奠定边界。

## 兼容性

- 保留现有 Bundle ID、偏好设置 Key 和数据格式，覆盖旧测试版不会丢失最近仓库
  与本地设置。
- 构建产物为 `GitCurrent.app`。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`GitCurrent.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：178 项通过，3 项环境相关用例按预期跳过。
- macOS arm64 Debug 与 Release 构建通过。
- Release ZIP 同时提供 SHA-256 校验文件。
