# GitCurrent v0.1.0-test.8

这是 GitCurrent 的第八个 GitHub 测试版本，重点验证主窗口改动文件浏览体验以及
代码结构重构后的稳定性。本版本不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- Working Copy 与 History 使用统一的改动文件浏览器，保持文件列表、选中状态和
  Diff 展示方式一致。
- History 下方文件区域和 Diff 区域支持联动调整尺寸，并提供原生分割线拖拽光标。
- 将主窗口侧边栏、工具栏、仓库状态栏、欢迎页和提交 Diff 弹窗抽取为独立组件。
- 将 Tags、Remotes、Worktrees、Submodules、Git LFS 和 Git Hooks 侧边栏区块拆为
  可独立维护的领域组件。
- 将 OperationPlanner、GitEngine 支持逻辑和仓库领域模型按功能域拆分，降低单文件
  复杂度并保持现有公开接口兼容。
- 清理 History 已失效的旧视图实现，并将改动文件选择状态收紧为明确的单文件状态。
- 补充欢迎页、Working Copy、History、分栏布局和拖拽光标相关测试。

## 兼容性

- 保留现有 Bundle ID、偏好设置 Key 和数据格式，覆盖旧测试版不会丢失最近仓库
  与本地设置。
- 构建产物为 `GitCurrent.app`，应用版本为 `0.1.0 (8)`。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 内置 Git/Git LFS 工具链为 Apple Silicon 版本，因此本测试版仅支持 arm64 Mac。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`GitCurrent.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：206 项通过，1 项 Git LFS 环境用例按预期跳过。
- macOS arm64 Debug 与 Release 构建通过。
- Release ZIP 同时提供 SHA-256 校验文件。
