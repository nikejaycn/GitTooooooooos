# Current v0.1.0-test.2

这是 Current 的第二个 GitHub 测试版本，用于验证原生 macOS Git 工作台的主界面、
仓库导航和远程分支工作流，不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- 完成三栏式仓库工作台和分层分支侧边栏。
- 补全工作区、提交历史、文件历史、Blame 和上下文 Inspector 导航。
- Remote Branches 支持层级展示。
- 双击远程分支时，自动创建同名本地分支、设置 upstream 并切换过去。
- 如果同名本地分支已存在，直接切换到现有本地分支。
- 远程分支检出支持工作区保护和自动 stash 工作流。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`Current.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：162 项通过，3 项环境预期跳过。
- macOS arm64 Release 构建通过。
- Release ZIP 会同时提供 SHA-256 校验文件。
