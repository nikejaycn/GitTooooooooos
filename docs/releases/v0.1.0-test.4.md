# GitCurrent v0.1.0-test.4

这是 GitCurrent 更名后的首个 GitHub 测试版本，重点验证新品牌与原生 macOS
AppIcon，以及 History 工作区的可调整布局，不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- 应用由 Current 更名为 GitCurrent，更直接表达原生 Git 客户端定位。
- 新增由 ImageGen 设计的完整 macOS AppIcon，覆盖 16–1024px。
- 欢迎页、窗口标题、状态栏、设置、诊断包和 CLI 提示统一使用 GitCurrent 品牌。
- History 上下工作区支持拖动调整高度，区域内容跟随尺寸同步变化。
- History 下方 Changed Files、提交信息和 File Diff 区域支持独立调整。
- 横向分割线显示上下拖拽光标，纵向分割线显示左右拖拽光标。
- History 数据加载后默认选择第一行，减少首次进入时的空白状态。

## 兼容性

- 保留原 Bundle ID 和偏好设置 Key，覆盖旧测试版不会丢失最近仓库与本地设置。
- 构建产物已更名为 `GitCurrent.app`。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`GitCurrent.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：173 项通过，3 项环境相关用例按预期跳过。
- macOS arm64 Release 构建通过。
- AppIcon 10 个 macOS 尺寸槽位与 Alpha 通道校验通过。
- 新名称、欢迎页图标和可调整 History 工作区已完成真实 GUI 验收。
- Release ZIP 同时提供 SHA-256 校验文件。
