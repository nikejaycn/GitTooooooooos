# Current v0.1.0-test.3

这是 Current 的第三个 GitHub 测试版本，重点验证可调整的原生 macOS 工作区布局，
以及所有 Changed Files 文件列表的 Diff 查看体验，不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- 主导航边栏支持拖动调整宽度。
- Working Copy 文件栏支持拖动调整宽度。
- Working Copy 中 staged、unstaged 和 untracked 文件均可点击查看 Diff。
- History 单提交的 Changed Files 支持点击查看父提交到当前提交的文件 Diff。
- History 多提交比较的 Changed Files 支持点击查看 base 到 target 的文件 Diff。
- Commit Diff 支持 Unified、Side-by-Side 和空白过滤选项。
- 修正单提交 Diff 的比较方向，确保内容按“父提交 → 当前提交”展示。
- 保留 Remote Branches 双击创建并切换本地跟踪分支的工作流。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`Current.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：166 项通过，3 项环境预期跳过。
- macOS arm64 Release 构建通过。
- 主边栏、Working Copy 分栏和 Changed Files Diff 已完成真实 GUI 验收。
- Release ZIP 会同时提供 SHA-256 校验文件。
