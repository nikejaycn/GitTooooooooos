# GitCurrent v0.1.0-test.7

这是 GitCurrent 的第七个 GitHub 测试版本，重点验证应用状态、仓库监听和 Git
执行层拆分后的稳定性与可维护性。本版本不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- 将 Git 执行层按分支、历史、远程、仓库能力和工作区操作拆分为独立实现文件，
  保持统一协议并降低单文件复杂度。
- 抽取仓库历史会话，集中管理分页、图谱、搜索和提交比较状态。
- 抽取 Diff 与文件洞察会话，集中管理工作区 Diff、提交 Diff、文件历史和 Blame
  的加载及清理状态。
- 引入统一的 latest-wins 异步任务协调器，避免过期请求覆盖较新的界面状态。
- 抽取仓库监听生命周期，统一启动、替换和停止 FSEvents 会话。
- 抽取最近仓库目录，集中处理收藏、移除、关闭记录和数量上限。
- 移除主窗口 History 工作区已经不再使用的转发参数，继续降低视图耦合。
- 补充异步任务、最近仓库、历史会话、文件检查会话和仓库监听生命周期测试。

## 兼容性

- 保留现有 Bundle ID、偏好设置 Key 和数据格式，覆盖旧测试版不会丢失最近仓库
  与本地设置。
- 构建产物为 `GitCurrent.app`，应用版本为 `0.1.0 (7)`。

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 内置 Git/Git LFS 工具链为 Apple Silicon 版本，因此本测试版仅支持 arm64 Mac。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`GitCurrent.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：204 项通过，3 项环境相关用例按预期跳过。
- macOS 14 Release 构建通过。
- 内置 Git 2.55.0 与 Git LFS 3.7.1 校验通过。
- Release ZIP 同时提供 SHA-256 校验文件。
