# GitCurrent v0.1.0-test.11

这是 GitCurrent 的第十一个 GitHub 测试版本，重点验证主窗口历史与改动文件浏览体验、
Developer ID 签名、公证和 macOS 安装包发布链路。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 本次重点

- History 与 Working Copy 使用统一的改动文件列表和 Diff 展示方式。
- History 下方文件列表与 Diff 区域支持独立拖拽调整尺寸，内容会随分栏尺寸同步布局，
  分割线悬停时显示原生拖拽光标。
- Local Branches 与 Remote Branches 的选中状态使用统一的侧边栏高亮效果。
- 保留提交图谱、提交比较、批量 Patch、远程提交链接和上下文操作能力。
- Release 使用 Developer ID Application 签名，并启用 Hardened Runtime。
- 生成已公证的 arm64 ZIP 和拖拽安装 DMG，DMG 内含 `/Applications` 快捷方式。

## 版本与兼容性

- Bundle ID：`com.fun2ex.Current`
- 应用版本：`0.1.0 (11)`
- 内置 Git/Git LFS 工具链为 Apple Silicon 版本，因此本测试版仅支持 arm64 Mac。
- 保留现有 Bundle ID、偏好设置 Key 和数据格式，覆盖旧测试版不会丢失最近仓库与本地
  设置。

## 验证

- Developer ID Application 签名验证通过。
- 内置 Git/Git LFS 工具链签名和完整性校验通过。
- ZIP 与 DMG 均通过 Apple Notarization，DMG staple/validate 通过。
- 挂载后的 App 通过 `codesign --verify --deep --strict`。
- `git diff --check` 和打包脚本语法校验通过。

## 已知限制

- 当前发布产物为 arm64；Intel Mac 需要后续增加 x86_64 或 Universal 构建。
- Sparkle 自动更新通道和 EdDSA 更新签名尚未启用。
