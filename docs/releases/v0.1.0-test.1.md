# Current v0.1.0-test.1

这是 Current 的首个 GitHub 测试版本，用于验证核心 Git 工作流、原生 macOS 界面和打包内容，
不作为正式生产版本分发。

## 运行要求

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本

## 测试范围

- 工作区状态、暂存、取消暂存、提交与 Diff
- Commit Graph、历史搜索、提交操作与 Inspector
- 分支、Tag、Remote、Stash、Worktree、Submodule、Git LFS 和 Hooks
- File History、Blame、冲突解决与 Interactive Rebase
- 原生三段式内容布局、最小窗口与深色外观
- 内置 Git 2.55.0、Git LFS 3.7.1 和 Keychain credential helper

## 重要限制

- 此构建未使用 Developer ID 签名，也未经过 Apple 公证。
- Sparkle 更新通道和 EdDSA 更新签名尚未启用。
- 仅用于受控测试，不应作为正式版本分发。

首次启动时，macOS 可能阻止打开未签名应用。请在 Finder 中按住 Control 点击
`Current.app`，选择“打开”，然后确认启动；不要关闭系统安全机制。

## 验证

- Swift 完整测试：155 项通过，3 项环境预期跳过。
- macOS arm64 Release 构建通过。
- 内置 Git / Git LFS / Keychain helper 验证通过。
- Release ZIP 会同时提供 SHA-256 校验值。
