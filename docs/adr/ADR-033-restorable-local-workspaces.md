# ADR-033：可恢复的原生 Local Workspace

- 状态：Accepted
- 日期：2026-07-25
- 范围：APP-05、COLLAB-01

## 决策

每个 SwiftUI `WindowGroup` Scene 拥有独立 `AppModel`、`RepositoryActor` 和仓库监听会话。
窗口之间只共享持久化设置、最近仓库与关闭历史，不共享当前仓库、选择、Diff、提交输入或 Git
操作状态。

Scene 使用包含稳定 UUID 与标准化仓库路径的 `Codable` 值。SwiftUI/macOS 负责保存仍打开
窗口及原生标签页的 Scene 状态；应用在恢复 Scene 时重新验证并打开对应仓库，不持久化 Git
凭据、进程或可变仓库快照。

最近仓库菜单提供“Open in New Window”。macOS 可以通过系统 Window 菜单把这些窗口合并为
原生标签页。收藏仓库按最近打开时间映射到 ⌘1–⌘9。

## 关闭与恢复

已关闭仓库保存到最多 20 项、去重的路径栈。⇧⌘T 取出最近一项并创建新的独立 Scene；仓库
重新打开后即从关闭历史移除。历史只含本地路径，不含凭据或仓库内容。

应用异常退出或系统恢复时，以 Scene 的 Codable 状态为准；关闭历史是显式关闭后的补充入口，
不替代系统窗口恢复。

## 边界

- v1 使用 macOS 原生窗口标签，不实现应用内自绘标签栏。
- 同一路径允许在不同窗口同时打开；每个窗口仍有独立读取模型和取消域。
- 设置由 UserDefaults 作为持久化真源。已经打开的窗口不承诺所有设置项跨窗口瞬时同步，重新
  打开窗口后会读取最新值。
